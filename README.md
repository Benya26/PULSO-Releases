# PULSO — Descargas oficiales

Repositorio público exclusivo para distribuir **PULSO** en Windows y Android. El código fuente del juego se desarrolla por separado y sigue siendo privado.

> **Estado:** el actualizador integrado está en fase de pruebas. No instales archivos que no aparezcan en una versión oficial verificada.

## Dónde descargar

- [Versiones publicadas](https://github.com/Benya26/PULSO-Releases/releases)
- [Última versión publicada](https://github.com/Benya26/PULSO-Releases/releases/latest), cuando exista

**Windows:** se distribuirá un instalador `.exe`. Las actualizaciones posteriores utilizarán archivos firmados y verificados desde la propia aplicación.

**Android:** se distribuirán APK según arquitectura. El dispositivo solicitará confirmación antes de instalar actualizaciones. La firma Android debe mantenerse igual en todas las versiones.

## Progreso y seguridad

Antes de sustituir una instalación de prueba, exporta tu progreso desde el juego y conserva una copia privada.

No hay ninguna obligación de estar conectado a Internet: PULSO está diseñado para funcionar sin conexión.

## Publicación y actualizaciones

El archivo de control `latest.json` es utilizado por Windows y `android.json` por Android. Se generan automáticamente **solamente después de publicar una versión en GitHub Releases**, tras comprobar que sus instaladores están completos. La publicación no se realiza automáticamente por subir cambios al código.

**Nunca** deben subirse claves privadas, contraseñas, keystores, copias de partidas ni archivos internos de desarrollo a este repositorio público.
